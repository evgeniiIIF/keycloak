# Fix: Admin-Force-Logout не доходит до BFF

## Проблема

Keycloak лог: `Some clients have not been logged out for user testuser in TestRealm realm: bfft`

Keycloak **пытается** отправить Back-Channel Logout клиенту `bfft`, но не может — у клиента не настроен Backchannel Logout URL.

## Решение

### 1. Настроить Backchannel Logout URL в Keycloak

В Keycloak Admin → Clients → `bfft` → Login Settings:
- **Backchannel Logout URL**: `http://bff:3000/api/auth/backchannel-logout`
- **Backchannel Logout Session Required**: ON

Если URL не виден в UI — попробовать через Keycloak Admin REST API:
```
PUT /admin/realms/TestRealm/clients/{client-uuid}
{
  "attributes": {
    "backchannel.logout.url": "http://bff:3000/api/auth/backchannel-logout",
    "backchannel.logout.session.required": "true"
  }
}
```

### 2. Добавить эндпоинт backchannel-logout в BFF

**Файл**: `bff/src/controllers/auth.controller.ts`

POST `/api/auth/backchannel-logout` — принимает logout token от Keycloak, находит сессию по `sid` или `sub`, удаляет из Redis.

Keycloak отправляет logout token (JWT) с claim'ами:
- `sub` — user ID
- `sid` — session ID (если backchannel.logout.session.required=true)
- `events` — содержит `http://schemas.openid.net/event/backchannel-logout`

### 3. Убрать ненужные SPI env-переменные

**Файл**: `docker-compose.yml`

Убрать `KC_SPI_EVENTS_LISTENER_EXT_EVENT_HTTP_*` — они не нужны, Back-Channel Logout работает без SPI.

### 4. Добавить JWKS валидацию logout token

**Файл**: `bff/package.json` — добавить `jose` (для JWT валидации через JWKS Keycloak)

## Файлы

| Файл | Изменение |
|------|-----------|
| `docker-compose.yml` | Убрать SPI env-переменные |
| `bff/src/controllers/auth.controller.ts` | Добавить POST backchannel-logout |
| `bff/src/configs/oidc.config.ts` | Добавить jwksUri |
| `bff/package.json` | Добавить `jose` |

## Верификация

1. `docker compose down && docker compose up -d --build`
2. Keycloak → Clients → bfft → Backchannel Logout URL = `http://bff:3000/api/auth/backchannel-logout`
3. Логин как testuser
4. Keycloak → Sessions → принудительный logout
5. В логах BFF: лог получения logout token и удаления сессии
6. Ключ `user_sessions:testuser` удалён из Redis
