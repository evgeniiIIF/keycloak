# Fix: BFF service Cannot find module '/app/dist/main'

## Problem
`nest start --watch` компилирует успешно (0 errors), но `dist/main.js` не создаётся. Причина: `tsconfig.json` имеет `"incremental": true`, но нет `"include"`. Файл `tsconfig.tsbuildinfo` кеширует состояние сборки — tsc думает "ничего не изменилось" и пропускает запись в `dist/`, даже если `dist/` не существует.

## Fix

### 1. `bff/tsconfig.json` — добавить `include` и убрать `incremental`
- Добавить `"include": ["src/**/*"]`
- Убрать `"incremental": true` (или удалить `tsconfig.tsbuildinfo` при каждом build)

### 2. `bff/.gitignore` — добавить `dist` и `tsconfig.tsbuildinfo`
Чтобы stale buildinfo не попадал в git и не монтировался в контейнер.

### 3. Верифицировать
```bash
docker compose down -v && docker compose up --build
# bff_service должен стартовать без MODULE_NOT_FOUND
```
