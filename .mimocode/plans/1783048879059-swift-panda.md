# Рефакторинг HttpService: убрать request(), добавить типизированные методы

## Проблема

Контроллер `protected_service.controller.ts` использует `httpService.request()` напрямую вместо типизированных методов, потому что существующие `get`/`post`/`put` **не принимают конфиг** (headers, responseType и т.д.) — только `params`. Это делает `httpService` бесполезной обёрткой, а контроллер — дублирует логику, которую уже делают интерцепторы.

### Конкретные проблемы

1. **`httpService.get/post/put` не принимают `AxiosRequestConfig`** — нет способа передать `headers`, `responseType`, `responseContentType` и т.д. Вынужденно используется `request()`.
2. **Контроллер дублирует `Authorization` header** вручную (строки 33-34, 70-71), хотя интерцептор в `axios.ts` уже делает это автоматически по `X-Session-ID`. Это избыточно и потенциально некорректно.
3. **Нет методов `delete` и `patch`** — их приходится делать через `request()`.
4. **Сломанный импорт** в `app.module.ts:3` — `import { ProtectedController } from '@controllers/protected.controller'` — файл не существует.

## План изменений

### 1. `bff/src/http/httpService.ts` — расширить API

Добавить необязательный параметр `config` во все существующие методы + добавить `delete`, `patch`:

```ts
public async get<T = any>(url: string, params?: any, config?: AxiosRequestConfig): Promise<AxiosResponse<T>> {
  return this.client.get<T>(url, { params, ...config });
}

public async post<T = any>(url: string, data?: any, params?: any, config?: AxiosRequestConfig): Promise<AxiosResponse<T>> {
  return this.client.post<T>(url, data, { params, ...config });
}

public async put<T = any>(url: string, data?: any, params?: any, config?: AxiosRequestConfig): Promise<AxiosResponse<T>> {
  return this.client.put<T>(url, data, { params, ...config });
}

public async patch<T = any>(url: string, data?: any, params?: any, config?: AxiosRequestConfig): Promise<AxiosResponse<T>> {
  return this.client.patch<T>(url, data, { params, ...config });
}

public async delete<T = any>(url: string, params?: any, config?: AxiosRequestConfig): Promise<AxiosResponse<T>> {
  return this.client.delete<T>(url, { params, ...config });
}
```

Убрать метод `request()` — он не должен быть публичным API сервиса.

### 2. `bff/src/controllers/protected_service.controller.ts` — упростить

Контроллер — это прокси для protected-service. Переписать на использование `httpService.get` / `httpService.post`:

- Убрать ручную установку `Authorization` — интерцептор уже делает это по `X-Session-ID`
- Использовать `httpService.get(url, null, { responseType: 'arraybuffer' })` вместо `httpService.request({ method: 'GET', ... })`
- Использовать `httpService.post(url, data, null, { responseType: 'arraybuffer' })` вместо `httpService.request({ method: 'POST', ... })`

До:
```ts
const response = await httpService.request({
  url: targetUrl,
  method: 'GET',
  headers: { 'Authorization': `Bearer ${req.userSession.accessToken}`, 'X-Session-ID': sessionId },
  responseType: 'arraybuffer',
});
```

После:
```ts
const response = await httpService.get(targetUrl, null, {
  headers: { 'X-Session-ID': sessionId },
  responseType: 'arraybuffer',
});
```

### 3. `bff/src/app.module.ts` — убрать сломанный импорт

Удалить строку 3 и убрать `ProtectedController` из массива `controllers` (файл `protected.controller.ts` не существует).
