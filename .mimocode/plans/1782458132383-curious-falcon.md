# Plan: Enhance logging — colors, detail, context

## Goal
Make all logs in bff_service and protected_service more informative and visually clear in Docker logs: richer error context, structured fields, and consistent colored output.

---

## 1. `protected-service/index.js` — Enhance logger + JWT verification

**Current state:** Basic `log(level, msg)` with 3 colors. JWT catch only logs `e.message`.

**Changes:**
- Add `logWithFields(service, level, msg, fields?)` — prints structured key=value pairs after the message (e.g. `user=testuser exp=10:05:11 issuer=TestRealm`)
- Decode JWT payload before verification to extract claims for logging
- On JWT success: log `user`, `exp`, `iss`, `aud`
- On JWT failure: log the specific failure reason (`exp` claim, `iss` mismatch, `aud` mismatch, signature invalid), plus the token header `kid` and `alg`
- Add incoming request logging: `→ GET /` at DEBUG level
- Add `CURL` color constant for request logging

**File:** `/home/jon/Projects/research-web-projects/keycloak/protected-service/index.js`

---

## 2. `bff/src/utils/logger.ts` — Add structured fields + date

**Current state:** `log(service, level, message)` with service+level colors.

**Changes:**
- Add optional `fields?: Record<string, string>` parameter to `log()`
- When fields are provided, append them as colored `key=value` pairs after the message
- Add date to timestamp: `2026-06-26 10:05:11` format (not just time)
- Add `RequestLogger` service color for proxy requests
- Export structured helper: `logInfo(service, msg, fields?)`, etc.
- Keep backward-compatible `Logger.info/warn/error/debug` signatures

**File:** `/home/jon/Projects/research-web-projects/keycloak/bff/src/utils/logger.ts`

## 3. `bff/src/http/axios.ts` — Richer error context

**Current state:** Logs `401 from ${url}` and `Refresh token expired (invalid_grant)`.

**Changes:**
- `handleInvalidAccessToken`: log HTTP status, target URL, session ID (full), reason
  - `401 from http://protected-service:8080/, refreshing token... [session=117b501c]`
- `handleInvalidRefreshToken`: log HTTP status + Keycloak error detail
  - `Refresh token failed: 400 invalid_grant — Token is not active [session=117b501c]`
- `handleInvalidAccessToken` catch block: same format as above
- Add `RequestLogger` tag to proxy-related logs

**File:** `/home/jon/Projects/research-web-projects/keycloak/bff/src/http/axios.ts`
