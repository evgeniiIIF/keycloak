# План: Рефакторинг + комментирование auth.service.ts и session.guard.ts

## Что делаем

### 1. Рефакторинг: разделение state и code_verifier в Redis

**Было (неправильно):**
```typescript
await redisClient.set(`state:${state}`, code_verifier, 'EX', config.auth.stateTtl);
```
state использовался и как CSRF-токен, и как ключ для PKCE — смешение ответственности.

**Стало (правильно):**
```typescript
await redisClient.set(`oauth:${state}`, code_verifier, 'EX', config.auth.stateTtl);
```
Один ключ `oauth:{state}` хранит code_verifier. Проверка CSRF: если `oauth:{state}` нет в Redis — state подделан.

- Цепочки: каждый шаг взаимодействия (бэкенд ↔ Keycloak ↔ Redis)
- Inline-комментарии для неочевидных строк
