# Логика авторизации: ошибки 401, 403, 400 + invalid_grant

## Архитектура

```
Клиент (React, :8082)
  → BFF (NestJS, :3000) — сессии в Redis, SecurityMiddleware
    → Protected Service (Express, :8083) — JWT-верификация через JWKS
```

---

## 401 Unauthorized — "ты не аутентифицирован"

**Единственный источник 401** — Protected Service при локальной проверке JWT через JWKS.

### Protected Service (protected-service/index.js)

| Строка | Условие | Ответ |
|--------|---------|-------|
| 54 | Нет `Authorization: Bearer` заголовка | `401 Unauthorized: Missing Bearer Token` |
| 97 | `jwtVerify()` упал (expired / wrong issuer / wrong audience / bad signature) | `401 Unauthorized: Invalid Token` |

### Цепочка: 401 → refresh → (ok | invalid_grant → 401 → login)

```
Protected Service → 401 (токен истёк/невалиден)
  ↓
BFF HttpClient.handle401() перехватывает
  ↓
Пытается обновить access_token через Keycloak refresh_token
  ↓
├─ Успех → retry оригинального запроса с новым токеном (клиент ничего не видит)
  ↓
└─ Keycloak вернул 400 + invalid_grant
     ↓
   BFF: уничтожает сессию, чистит Redis
     ↓
   BFF → 401 "Session expired" на фронтенд
     ↓
   Клиентский Axios interceptor → redirect на /logout → login
```

## 403 Forbidden — "ты аутентифицирован, но не авторизован"

**Единственный источник 403** — SecurityMiddleware (bff/src/middleware/security.middleware.ts).

| Строка | Условие | Исключение | Смысл |
|--------|---------|------------|-------|
| 40 | Нет RouteRule для path+method | `ForbiddenException('Route not configured')` | Deny-by-default |
| 77 | CSRF cookie/header отсутствуют или не совпадают | `ForbiddenException('Invalid CSRF token')` | CSRF не пройден |
| 81 | CSRF cookie != session.csrfToken | `ForbiddenException('CSRF token mismatch')` | Токен не совпадает |
| 89 | Нет сессии на этапе проверки ролей | `ForbiddenException('No session')` | Defensive check |
| 110 | JWT роли не содержат требуемые | `ForbiddenException('Insufficient roles')` | RBAC отказ |

Правила определены в `bff/src/config/routes.ts` — массив `ROUTE_RULES`, проверяется сверху вниз, первое совпадение. Незарегистрированный route → 403.

## 400 + invalid_grant — "Refresh token отклонён Keycloak"

### Где обрабатывается

**KeycloakClient** (bff/src/services/keycloak-client.ts:54-56) — ре-throwит ошибку:
```typescript
if (status === 400 && kcError === 'invalid_grant') {
  throw err;
}
```

**HttpClient** (bff/src/services/http-client.ts:105-118) — ловит и уничтожает сессию:
```typescript
if (isInvalidGrant) {
  // логирует причину
  // unregisterSession() из Redis
  // session.destroy()
  throw new UnauthorizedException('Session expired');  // → 401 клиенту
}
```

### Причины invalid_grant

- Refresh token истёк (SSO Session Idle/Max)
- Refresh token отозван (logout, admin revocation)
- Refresh token уже использован (rotation violation / reuse detection)

## Глобальный фильтр ошибок (bff/src/filters/http-exception.filter.ts)

Все NestJS HttpException проходят через `HttpExceptionFilter` → JSON:
```json
{ "statusCode": 401 | 403, "message": "...", "timestamp": "..." }
```
