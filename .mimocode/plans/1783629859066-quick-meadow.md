# Plan: Создать SESSION_ARCHITECTURE.md

## Задача

Создать файл `SESSION_ARCHITECTURE.md` в корне `bff/` с документацией архитектуры сессий.

## Содержимое файла

### 1. Три уровня хранения сессии
- Кука на клиенте (`connect.sid`) — только ID сессии
- Данные в Redis (`sess:<sessionId>`) — автоматически через `connect-redis`
- Индекс сессий пользователя (`user_sessions:<userId>`) — наш `RedisService`

### 2. Кто что хранит
- `connect-redis` — данные сессии (токены, пользователь) автоматически при `session.save()`
- `RedisService` — индекс (список сессий пользователя) вручную

### 3. Поток данных
- login → callback → usage → logout
