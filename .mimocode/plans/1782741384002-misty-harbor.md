# Переименование клиента bff → bff-client

## Код (автоматически)
Заменить `bff` на `bff-client` в фолбэках:
1. `bff/src/configs/oidc.config.ts:9` — `'bff'` → `'bff-client'`
2. `bff/src/configs/configuration.ts:18` — `'bff'` → `'bff-client'`
3. `bff/.env.example:8` — `KEYCLOAK_CLIENT_ID=bff` → `KEYCLOAK_CLIENT_ID=bff-client`
4. `.env:15` — `KEYCLOAK_CLIENT_ID=bff` → `KEYCLOAK_CLIENT_ID=bff-client`

## Keycloak Admin Console (вручную)
1. Clients → выбрать `bff`
2. Поле **Client ID** → заменить на `bff-client`
3. Сохранить

## Верификация
Hot-reload перезапустит BFF. Проверить логин — URL должен содержать `client_id=bff-client`.
