# План: Мгновенный логаут при завершении сессии админом в Keycloak

## Суть
Админ завершает сессию пользователя в Keycloak → Keycloak отправляет admin event в BFF → BFF удаляет сессию из Redis → следующий запрос фронтенда получает 401 → фронтенд редиректит на логин.

## Текущее состояние
- `docker-compose.yml:30-31` — Keycloak настроен отправлять admin events на `bff:3000/api/auth/admin-events`
- **Обработчик этого эндпоинта не существует** — Keycloak шлёт, но BFF отвечает 404
- Сессии хранятся в Redis с ключом `sess:<id>`, содержат `userInfo.sub` (ID пользователя)

## Архитектура

```
Admin → Keycloak: "Terminate Session" (user X)
    ↓ Keycloak HTTP event
    ↓ POST http://bff:3000/api/auth/admin-events
    ↓ { resourceType: "USER_SESSION", operationType: "DELETE", details: { user_id: "..." } }
    ↓ AdminEventsController → sessionService.deleteSessionsByUser(user_id)
    ↓ Redis: DEL sess:<id1>, DEL sess:<id2>, ...
    ↓
Frontend → BFF GET /api/me → 401 (сессия удалена)
    ↓ AuthContext → setAuthenticated(false) → редирект на /login
```

## Изменения

### 1. `bff/src/services/session.service.ts`

Добавить два метода:

- **`addUserSession(userId: string, sessionId: string)`** — при создании сессии добавляет ID в Redis SET `user_sessions:<userId>`
- **`deleteSessionsByUser(userId: string)`** — находит все сессии пользователя через `SMEMBERS user_sessions:<userId>`, удаляет каждую (`DEL sess:<id>`), затем удаляет сам SET

В `createSession()` — после сохранения сессии вызвать `addUserSession(userInfo.sub, sessionId)`.
В `deleteSession()` — убрать ID из SET (`SREM`).

### 2. Создать `bff/src/controllers/admin-events.controller.ts`

```ts
@Controller('api/auth')
export class AdminEventsController {
  constructor(private sessionService: SessionService) {}

  @Post('admin-events')
  async handleAdminEvent(@Body() event: any) {
    if (event.resourceType === 'USER_SESSION' && event.operationType === 'DELETE') {
      const userId = event.details?.user_id;
      if (userId) {
        await this.sessionService.deleteSessionsByUser(userId);
      }
    }
    return { status: 'ok' };
  }
}
```

### 3. `bff/src/app.module.ts`

Добавить `AdminEventsController` в массив `controllers`.

## Верификация

1. `docker compose up --build`
2. Залогиниться через фронтенд
3. Открыть Keycloak admin → Sessions → Terminate session пользователя
4. Следующий запрос фронтенда к `/api/me` должен вернуть 401
5. Фронтенд переключится на неавторизованное состояние
