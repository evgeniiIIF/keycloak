# Plan: Replace `unknown` with proper types

## Problem
TypeScript files in `bff/src/` contain lazy `unknown` type annotations in function signatures, especially `data?: unknown` and `Record<string, unknown>`. These should use generics or more specific types.

## Scope
4 files to modify. `catch (err: unknown)` blocks and error-accepting utilities are correct and stay unchanged.

---

## Changes

### 1. `bff/src/shared/logger.ts` — Define `LogFields` type

**Current**: `Record<string, unknown>` used 9 times for log fields
**Fix**: Export a `LogFields` type alias:
```typescript
type LogField = string | number | boolean | null | undefined;
export type LogFields = Record<string, LogField>;
```
Replace all `Record<string, unknown>` parameter and return types with `LogFields`.

All actual callers pass string/number values — this is type-safe.

### 2. `bff/src/services/http-client.ts` — Generics for HTTP methods

**Current**:
```typescript
async get<T>(url: string, params?: Record<string, unknown>): Promise<T>
async post<T>(url: string, data?: unknown): Promise<T>
async put<T>(url: string, data?: unknown): Promise<T>
async patch<T>(url: string, data?: unknown): Promise<T>
```

**Fix**: Clean generics — `P` for params, `D` for data body, no defaults:
```typescript
async get<T, P>(url: string, params?: P): Promise<T>
async post<T, D>(url: string, data?: D): Promise<T>
async put<T, D>(url: string, data?: D): Promise<T>
async patch<T, D>(url: string, data?: D): Promise<T>
```

Callers specify types explicitly: `http.get<Resp, MyParams>(url, params)`.

### 3. `bff/src/controllers/proxy.controller.ts` — callers + dispatch map

**proxyGet**:
```typescript
private async proxyGet(path: string, res: Response) {
  try {
    res.json(await this.http.get<any>(`${config.protectedServiceUrl}/${path}`));
  } catch (err: unknown) {
    this.proxyError(res, err, 'GET');
  }
}
```

**proxyMutate** — убираем явную аннотацию `Record<HttpMethod, () => Promise<unknown>>`:
```typescript
private async proxyMutate(path: string, req: Request, res: Response, method: HttpMethod) {
  const url = `${config.protectedServiceUrl}/${path}`;
  try {
    const methodFn: Record<HttpMethod, () => Promise<any>> = {
      POST: () => this.http.post(url, req.body),
      PUT: () => this.http.put(url, req.body),
      DELETE: () => this.http.delete(url),
      PATCH: () => this.http.patch(url, req.body),
    };
    const result = await methodFn[method]();
    res.json(result);
  } catch (err: unknown) {
    this.proxyError(res, err, method);
  }
}
```

Тип `Promise<any>` здесь осознанный — proxy не знает типы, результат сразу в `res.json()`.

### 4. `bff/src/interceptors/session-context.interceptor.ts` — Match NestJS contract

**Current**: `Observable<unknown>` return type
**Fix**: `Observable<any>` — matches the `NestInterceptor` interface contract from `@nestjs/common`.
