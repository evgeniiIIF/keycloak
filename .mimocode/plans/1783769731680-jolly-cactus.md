## Task 4: `bff/src/guards/auth.guard.spec.ts` — создать unit-тесты

**Файл не существует.** Создать `bff/src/guards/auth.guard.spec.ts`.

**Кейсы для покрытия:**
1. **Public endpoint** — `isPublic = true` → guard пропускает без проверки сессии
2. **RequireSession + нет сессии** — бросает `UnauthorizedException('No session')`
3. **RequireSession + токен истёк** — бросает `UnauthorizedException('Token expired')`
4. **RequireSession + токен валиден** — пропускает
5. **RequireCsrf + нет куки/хедера** — бросает `ForbiddenException('Invalid CSRF token')`
6. **RequireCsrf + mismatch** — бросает `ForbiddenException('Invalid CSRF token')`
7. **RequireCsrf + валидный токен** — пропускает
8. **Roles + нет роли** — бросает `ForbiddenException('Insufficient roles')`
9. **Roles + нужная роль (mode: any)** — пропускает
10. **Roles + все роли (mode: all)** — проверяет оба варианта

**Подход:**
- Jest + `Test.createTestingModule` для создания guard
- Мокаем `Reflector` через `jest.fn()` — `getAllAndOverride` возвращает нужное значение в зависимости от ключа
- Мокаем `ExecutionContext` с `getRequest()` возвращающим `{ session, cookies, headers }`
- Используем реальные JWT (или заглушку с правильной структурой) для проверки `decodeJwt`
