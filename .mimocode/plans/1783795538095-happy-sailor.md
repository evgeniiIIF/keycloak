# Один .env — единственный источник правды

## Проблема

Переменные разбросаны: часть в `.env`, часть захардкожена в `docker-compose.yml`, часть в `config.ts`. Непонятно где что задаётся.

## Решение

Один `.env` содержит ВСЁ. Docker-compose берёт оттуда. BFF config.ts читает оттуда.

### 1. Корневой `.env` — финальная версия

```env
# === Keycloak ===
KEYCLOAK_ADMIN=admin
KEYCLOAK_ADMIN_PASSWORD=admin
KEYCLOAK_REALM=TestRealm
KEYCLOAK_CLIENT_ID=bff-client
KEYCLOAK_CLIENT_SECRET=AQce4SdHum6sxqnreawz3ArsKm4tIx47
KC_HOSTNAME=localhost
KEYCLOAK_ISSUER=http://keycloak:8080/realms/TestRealm
KEYCLOAK_PUBLIC_ISSUER=http://localhost:8080/realms/TestRealm

# === Database ===
POSTGRES_DB=keycloak
POSTGRES_USER=keycloak
POSTGRES_PASSWORD=password

# === Redis ===
REDIS_HOST=redis
REDIS_PORT=6379

# === BFF ===
PORT=3000
NODE_ENV=development
SESSION_SECRET=a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2
FRONTEND_URL=http://localhost:8082
PROTECTED_SERVICE_URL=http://protected-service:8080

# === Frontend ===
VITE_API_URL=http://localhost:3000
```

### 2. `docker-compose.yml` — заменить хардкод на `${VAR}`

Было:
```yaml
bff:
  environment:
    KEYCLOAK_ISSUER: http://keycloak:8080/realms/${KEYCLOAK_REALM}
    KEYCLOAK_PUBLIC_ISSUER: http://localhost:8080/realms/${KEYCLOAK_REALM}
    REDIS_HOST: redis
    REDIS_PORT: 6379
    PROTECTED_SERVICE_URL: http://protected-service:8080
    FRONTEND_URL: http://localhost:8082
    CORS_ORIGINS: http://localhost:8082
```

Стало:
```yaml
bff:
  environment:
    KEYCLOAK_ISSUER: ${KEYCLOAK_ISSUER}
    KEYCLOAK_PUBLIC_ISSUER: ${KEYCLOAK_PUBLIC_ISSUER}
    REDIS_HOST: ${REDIS_HOST}
    REDIS_PORT: ${REDIS_PORT}
    PROTECTED_SERVICE_URL: ${PROTECTED_SERVICE_URL}
    FRONTEND_URL: ${FRONTEND_URL}
    CORS_ORIGINS: ${FRONTEND_URL}
```

Аналогично для `protected-service` и `keycloak` сервисов.

### 3. Удалить лишние файлы

- `bff/.env.example`
- `client/.env`
- `client/.env.example`

### 4. `client/vite.config.ts` — добавить `envDir: '..'`

```typescript
export default defineConfig({
  plugins: [react()],
  envDir: '..',
  server: { port: 3000, host: true }
})
```

### 5. Обновить `.env.example` — единый шаблон

```env
# === Keycloak ===
KEYCLOAK_ADMIN=
KEYCLOAK_ADMIN_PASSWORD=
KEYCLOAK_REALM=TestRealm
KEYCLOAK_CLIENT_ID=bff-client
KEYCLOAK_CLIENT_SECRET=
KC_HOSTNAME=localhost
KEYCLOAK_ISSUER=http://keycloak:8080/realms/TestRealm
KEYCLOAK_PUBLIC_ISSUER=http://localhost:8080/realms/TestRealm

# === Database ===
POSTGRES_DB=keycloak
POSTGRES_USER=keycloak
POSTGRES_PASSWORD=

# === Redis ===
REDIS_HOST=redis
REDIS_PORT=6379

# === BFF ===
PORT=3000
NODE_ENV=development
SESSION_SECRET=  # >= 32 chars
FRONTEND_URL=http://localhost:8082
PROTECTED_SERVICE_URL=http://protected-service:8080

# === Frontend ===
VITE_API_URL=http://localhost:3000
```

## Файлы

| Файл | Действие |
|------|----------|
| `.env` | Переписать — всё в одном месте |
| `.env.example` | Переписать — единый шаблон |
| `docker-compose.yml` | Заменить хардкод на `${VAR}` |
| `client/vite.config.ts` | Добавить `envDir: '..'` |
| `bff/.env.example` | **Удалить** |
| `client/.env` | **Удалить** |
| `client/.env.example` | **Удалить** |
