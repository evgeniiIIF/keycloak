# Plan: Refactor httpService and protected_service.controller

## Problem
1. `httpService.request()` used instead of convenience methods in controller
2. `responseType: 'arraybuffer'` unnecessary for JSON responses
3. No dedicated method for binary data — would cause copy-paste if needed later

## Solution

### Step 1: Update `bff/src/http/httpService.ts`
Add optional `config` param to existing methods + new `requestBinary` method:

```ts
public async get<T = any>(url: string, params?: any, config?: Partial<AxiosRequestConfig>): Promise<AxiosResponse<T>> {
  return this.client.get<T>(url, { ...config, params });
}

public async post<T = any>(url: string, data?: any, params?: any, config?: Partial<AxiosRequestConfig>): Promise<AxiosResponse<T>> {
  return this.client.post<T>(url, data, { ...config, params });
}

public async put<T = any>(url: string, data?: any, params?: any, config?: Partial<AxiosRequestConfig>): Promise<AxiosResponse<T>> {
  return this.client.put<T>(url, data, { ...config, params });
}

public async requestBinary(config: AxiosRequestConfig): Promise<AxiosResponse<ArrayBuffer>> {
  return this.client.request<ArrayBuffer>({ ...config, responseType: 'arraybuffer' });
}
```

### Step 2: Refactor `bff/src/controllers/protected_service.controller.ts`
Replace `httpService.request()` with convenience methods (no more `arraybuffer`):

**GET (line 29):**
```ts
const response = await httpService.get(targetUrl, undefined, {
  headers: {
    'Authorization': `Bearer ${req.userSession.accessToken}`,
    'X-Session-ID': sessionId,
  },
});
```

**POST (line 65):**
```ts
const response = await httpService.post(targetUrl, req.body, undefined, {
  headers: {
    'Authorization': `Bearer ${req.userSession.accessToken}`,
    'X-Session-ID': sessionId,
  },
});
```
