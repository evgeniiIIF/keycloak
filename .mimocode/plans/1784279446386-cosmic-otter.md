# Plan: Simplify session types — remove AuthSession

## Problem

Three types: `Session`, `BffSession`, `AuthSession`. `AuthSession` is used in 1 place (`applyToken`). Confusing.

## Solution

Two types:
- `Session` — express-session class (base)
- `BffSession` = `Session & Partial<SessionData>` (with custom fields)

`assertAuthenticated` returns `BffSession` (not `AuthSession`). `AuthSession` deleted.

### Changes

**`bff/src/shared/utils/assert-authenticated.ts`** — remove `AuthSession`, return `BffSession`:
```typescript
import { UnauthorizedException } from '@nestjs/common';
import type { BffSession } from '../../types/session';

export function assertAuthenticated(session: BffSession): BffSession {
  if (
    !session.accessToken ||
    !session.refreshToken ||
    !session.idToken ||
    !session.userInfo?.sub
  ) {
    throw new UnauthorizedException('Session not authenticated');
  }
  return session;
}
```

**`bff/src/gateway/services/axios-http-client.service.ts`** — remove `AuthSession` import, `applyToken` takes `BffSession`:
```typescript
import { assertAuthenticated } from '../../shared/utils/assert-authenticated';
// ...
private applyToken(session: BffSession, reqCfg: RetryableConfig) {
  if (session.accessToken) {
    if (!reqCfg.headers) reqCfg.headers = {} as any;
    reqCfg.headers.Authorization = `Bearer ${session.accessToken}`;
  }
}
```

Other files unchanged — they already use `BffSession` + `assertAuthenticated`.
