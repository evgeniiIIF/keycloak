# Обновление CLAUDE.md: flow-комментарии на русском

## Проблема
`// ─── Level N: Name ───` — это labels, а не объяснение. Читатель видит "Level 3" но не понимает что происходит.

## Решение
Комментарий-цепочка на русском вверху функции — объясняет алгоритм как историю.

## Формат

### Линейный поток
```typescript
// проверяем токен → проверяем replay → валидируем sub → удаляем сессии
async handleBackchannelLogout(logoutToken: string) { ... }
```

### Try/catch
```typescript
// Plan A: обновляем токен → повторяем запрос | Plan B: обрабатываем ошибку → пробрасываем
private async handleResponseError(error: AxiosError) {
```

### If/else ветвление
```typescript
// забираем lock → если получили → обновляем токен, если нет → ждём параллельное обновление | finally: освобождаем lock
private async performRefresh(session, config) { ... }
```

## Правила формата
1. **На русском** — объясняющий комментарий, не листинг методов
2. **`→`** — следующий шаг
3. **`|`** — разделитель веток (Plan A | Plan B, try | catch)
4. **`если/когда/ Plan A/B`** — условия и ветки
5. Кратко: одно предложение на функцию
6. Для простых функций — одна строка; для сложных — многострочный
