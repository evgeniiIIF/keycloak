# План: Кастомная тема входа для Keycloak

## Цель
Создать стильную светлую минималистичную форму входа для Keycloak 26.6 с полным сохранением нативной валидации и событий Keycloak.

## Структура файлов

```
themes/
  custom-login/
    login/
      theme.properties          # Конфигурация темы (parent=base)
      login.ftl                 # Основной шаблон формы входа
      resources/
        css/
          login.css             # Кастомные стили
```

## Шаг 1: Создать `themes/custom-login/login/theme.properties`

```properties
parent=base
import=common/keycloak
styles= css/login.css
```

Ключевые моменты:
- `parent=base` — наследует всю базовую функциональность Keycloak (JS-валитация, редиректы, обработку форм)
- Стили подключаются через `import` — Keycloak сам подключит CSS

## Шаг 2: Создать `themes/custom-login/login/login.ftl`

Критически важно сохранить все нативные Keycloak-поля:

### Обязательные элементы формы:
1. **Форма** — `<form id="kc-form-login" class="${(message.summary?has_content)?then('kc-error','')}" action="${url.loginAction}" method="post">`
2. **CSRF токен** — `<input type="hidden" name="kcCsrfToken" value="${kcCsrfToken!}">`
3. **Поле username/email** — `<input id="username" name="username" value="${(form.username!)?html}" .../>` с autocomplete
4. **Поле password** — `<input id="password" name="password" type="password" .../>` с autocomplete
5. **Remember me** — `<#if realm.rememberMe>...</#if>` чекбокс
6. **Submit кнопка** — `<input name="login" type="submit" value="${msg('doLogIn')}" ...>`
7. **Сообщения об ошибках** — `<#if message.summary?has_content><div id="kc-feedback" class="..."><div class="...">${message.summary}</div></div></#if>`

### Условные ссылки:
- **Регистрация** — `<#if realm.registrationAllowed><a href="${url.registrationUrl}">...</a></#if>`
- **Забыли пароль** — `<#if realm.resetPasswordAllowed><a href="${url.loginRestartFlowUrl}">...</a></#if>`
- **Username вместо Email** — `<#if !realm.loginWithEmailAllowed>...</#if>`

### Дополнительные Keycloak-интеграции:
- Social providers (Google, GitHub и т.д.) — `<#if social.providers?has_content>...</#if>`
- Статический контекст и логотип — `${url.resourcesPath}` и `${properties.logoUri!}`
- Password visibility toggle — JavaScript для показа/скрытия пароля

## Шаг 3: Создать `themes/custom-login/login/resources/css/login.css`

Дизайн: чистый светлый минимализм.
- Белый фон страницы, центрированная карточка формы
- Шрифт Inter/system-ui (как в React-приложении проекта)
- Мягкие тени, скруглённые углы (border-radius: 12px)
- Минималистичные инпуты с тонкой рамкой и фокус-эффектом
- Кнопка登录 — акцентный цвет `#646cff` (как в React-приложении) с hover-эффектом
- Сообщения об ошибках — мягкий красный фон
- Адаптивная верстка (mobile-first)

## Шаг 4: Изменить `docker-compose.yml`

Добавить volume mount к сервису `keycloak` (строки 16-35):

```yaml
  keycloak:
    image: quay.io/keycloak/keycloak:26.6
    container_name: keycloak_server
    command: start-dev
    volumes:
      - ./themes:/opt/keycloak/themes    # <-- ДОБАВИТЬ
    environment:
      # ... без изменений
```

## Шаг 5: Настройка через Keycloak Admin Console (после деплоя)

После запуска docker-compose, в Admin Console Keycloak (`http://localhost:8080`):
1. Зайти в **Realm Settings** → **Themes** вкладка
2. В поле **Login Theme** выбрать `custom-login`
3. Нажать **Save**

Это единственная ручная настройка — автоматизировать её нельзя без realm-export.json.

## Верификация

1. `docker compose up -d` — убедиться что контейнер стартует без ошибок
2. Открыть `http://localhost:3000/login` — должен отрисоваться кастомный UI
3. Проверить валидацию:
   - Пустая форма → ошибка "Invalid username or password"
   - Неверный пароль → ошибка
   - Кнопка "Show password" работает
   - Remember me работает
4. Проверить что регистрация (если включена в realm) ссылка работает
5. Проверить что "Forgot password?" ссылка работает
6. Проверить соц-провайдеры (если настроены) отображаются
7. `docker compose down && docker compose up -d` — после перезапуска тема сохраняется
