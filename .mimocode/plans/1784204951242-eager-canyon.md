# BFF = чистый прокси. Убрать всю валидацию.

## Принцип

BFF не проверяет ничего. Только прикрепляет токен и передаёт ошибки. Токены проверяет downstream сервис.

---

## Шаг 1: app.module.ts — убрать guards

Убрать `AuthGuard`, `CsrfGuard`, `RolesGuard`, `CsrfMiddleware`. Оставить только `SessionContextInterceptor`.

## Шаг 2: main.ts — убрать ValidationPipe

BFF не валидирует DTO.

## Шаг 3: auth.controller.ts — убрать guards с routes

Убрать `@RequireSession()`, `@RequireCsrf()`, `@Public()` с `/login`, `/callback`, `/api/me`, `/logout`. Убрать импорт `CallbackQueryDto`, использовать `Record<string, string>`.

## Шаг 4: axios-http-client.service.ts — упростить error handling

- Убрать `canRetry`, `handleRefreshError` как отдельные методы
- На 401 → try refresh → retry
- На invalid_grant → destroy session → throw 401
- На всё остальное → проброс оригинальной ошибки
- Lock mechanism (Redis) остаётся — предотвращает гонки refresh

## Шаг 5: auth.decorator.ts — оставить только @Public

Убрать `RequireSession`, `RequireCsrf`, `Roles`, `RolesMeta`.

## Шаг 6: auth.module.ts — убрать guards

Убрать guards из providers и exports.

## Шаг 7: shared.module.ts — убрать CsrfMiddleware

Убрать из providers и exports.

## Шаг 8: удалить мёртвые файлы

- `auth/guards/auth.guard.ts` + spec
- `auth/guards/roles.guard.ts` + spec
- `auth/guards/csrf.guard.ts` + spec
- `auth/dto/callback.dto.ts`
- `shared/middleware/csrf.middleware.ts`

## Что не трогаем

Auth flow, backchannel logout, session management, Redis, token refresh lock, HttpExceptionFilter, KeycloakClient, GatewayController.

## Верификация

1. `npm run build`
2. `npm test`
3. Ручная проверка: proxy без токена → ошибка от downstream; expired token → refresh + retry; invalid_grant → 401
