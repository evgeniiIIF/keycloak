# Очистка конфига Keycloak и мёртвого пакета

---

## 1. Удалить мёртвую зависимость `nest-keycloak-connect`

**Файл:** `bff/package.json`

Пакет нигде не импортируется. BFF реализует авторизацию вручную через `SessionGuard` + Redis.

**Действие:** Удалить строку `"nest-keycloak-connect": "latest"` из `dependencies`.

---

## 2. Консолидация конфига Keycloak

Сейчас настройки Keycloak в двух файлах с дублированием:
- `bff/src/configs/configuration.ts` — `config.keycloak` (realm, clientId, secret)
- `bff/src/configs/oidc.config.ts` — `oidcConfig` (issuer, hostname, port, clientId, clientSecret, redirectUri, scope, jwksUri)

### Шаг A: Добавить все поля из oidcConfig в config.keycloak

**Файл:** `bff/src/configs/configuration.ts`

Было:
```ts
keycloak: {
  realm: process.env.KEYCLOAK_REALM || 'master',
  clientId: process.env.KEYCLOAK_CLIENT_ID || 'bff-client',
  secret: process.env.KEYCLOAK_CLIENT_SECRET || 'secret-key',
},
```

Стало:
```ts
keycloak: {
  realm: process.env.KEYCLOAK_REALM || 'master',
  issuer: process.env.KEYCLOAK_ISSUER || 'http://localhost:8080/realms/TestRealm',
  hostname: process.env.KEYCLOAK_HOSTNAME || 'keycloak',
  port: parseInt(process.env.KEYCLOAK_PORT || '8080', 10),
  clientId: process.env.KEYCLOAK_CLIENT_ID || 'bff-client',
  clientSecret: process.env.KEYCLOAK_CLIENT_SECRET || 'secret-key',
  redirectUri: process.env.KEYCLOAK_REDIRECT_URI || 'http://localhost:3000/callback',
  scope: 'openid profile email',
  jwksUri: process.env.KEYCLOAK_JWKS_URI || 'http://localhost:8080/realms/TestRealm/protocol/openid-connect/certs',
},
```

### Шаг B: Удалить файл `bff/src/configs/oidc.config.ts`

### Шаг C: Обновить импорты в файлах

**`bff/src/services/auth.service.ts`:**
- Убрать строку `import { oidcConfig } from '@configs/oidc.config'`
- `oidcConfig.clientId` → `config.keycloak.clientId` (строки 50, 103)
- `oidcConfig.clientSecret` → `config.keycloak.clientSecret` (строки 51, 104)
- `oidcConfig.redirectUri` → `config.keycloak.redirectUri` (строки 52, 105)
- `oidcConfig.hostname` → `config.keycloak.hostname` (строки 62, 114)
- `oidcConfig.port` → `config.keycloak.port` (строки 62, 114)

**`bff/src/controllers/auth.controller.ts`:**
- Убрать строку `import { oidcConfig } from '@configs/oidc.config'`
- `oidcConfig.jwksUri` → `config.keycloak.jwksUri` (строка 104)
- `oidcConfig.issuer` → `config.keycloak.issuer` (строка 106)
