# Plan: Замена HttpService на HttpClient + AsyncLocalStorage

## Архитектура (как в Spring Security)

```
Guard: валидирует сессию → кладёт sessionId в AsyncLocalStorage
              ↓
Interceptor: берёт sessionId из AsyncLocalStorage → ставит Authorization
              ↓
Controller: вызывает httpClient.get(url) — без headers, без auth
```

## Изменения

### 1. `bff/src/http/request-context.ts` — создать

```typescript
import { AsyncLocalStorage } from 'async_hooks';

export const requestContext = new AsyncLocalStorage<{ sessionId: string }>();
```

### 2. `bff/src/guards/session.guard.ts` — модифицировать

Guard уже находит сессию в Redis. Добавляем: кладём `sessionId` в `AsyncLocalStorage` через `requestContext.run()`.

### 3. `bff/src/http/axios.ts` — модифицировать

Интерцептор читает `sessionId` из `requestContext.getStore()` вместо `config.headers?.['X-Session-ID']`.

### 4. `bff/src/http/httpService.ts` — замена класса

Заменить `HttpService` на `HttpClient` (как есть, без изменений).

### 5. `bff/src/controllers/protected_service.controller.ts` — упрощение

Убираем headers. Controller просто вызывает:
```typescript
const data = await httpClient.get(targetUrl);
res.json(data);
```
