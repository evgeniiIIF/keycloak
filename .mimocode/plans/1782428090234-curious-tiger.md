# Свой httpClient вместо @nestjs/axios

## Архитектура

```
bff/src/http/axios.ts      — один Axios instance + interceptor
bff/src/http/httpService.ts — httpClient с методами get/post/request + логирование
bff/src/app.module.ts      — убрать HttpModule
bff/src/main.ts            — убрать interceptor регистрацию
bff/src/services/auth.service.ts    — использовать httpClient
bff/src/services/proxy.service.ts   — использовать httpClient
bff/package.json           — убрать @nestjs/axios
```

## Файлы

### 1. `bff/src/http/axios.ts` — СОЗДАТЬ
Один Axios instance + interceptor для 401 → refresh → retry.

### 2. `bff/src/http/httpService.ts` — СОЗДАТЬ
Класс httpClient с методами get/post/request. Логирует запросы и ответы.

### 3. `bff/src/app.module.ts` — убрать HttpModule
### 4. `bff/src/main.ts` — убрать interceptor регистрацию
### 5. `bff/src/services/auth.service.ts` — использовать httpClient
### 6. `bff/src/services/proxy.service.ts` — использовать httpClient
### 7. `bff/package.json` — убрать @nestjs/axios

## Верификация
1. `npx tsc --noEmit`
2. `docker compose up`
