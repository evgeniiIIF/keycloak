# Session mutations through SessionService

## Goal
Все мутации сессии проходят через `SessionService` — очевидно и консистентно.

## Changes

### 1. `bff/src/session/services/session.service.ts` — добавить методы

```ts
setOAuth(session: BffSession, state: string, codeVerifier: string): void {
  session.oauth = { state, codeVerifier };
}

clearOAuth(session: BffSession): void {
  delete session.oauth;
}
```

### 2. `bff/src/auth/services/auth.service.ts` — использовать методы

**buildAuthorizationUrl:**
```diff
- session.oauth = { state, codeVerifier };
+ this.sessionService.setOAuth(session, state, codeVerifier);
```

**exchangeAndApplyCode:**
```diff
- delete session.oauth;
+ this.sessionService.clearOAuth(session);
```
