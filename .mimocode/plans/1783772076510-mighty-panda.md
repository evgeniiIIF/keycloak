# Полный аудит BFF: исправление 14 пунктов

## 1. Lock release — compare-and-delete (Lua)
**Файл:** `bff/src/shared/token-refresh-lock.ts`

Сейчас `release()` делает слепой `DEL`. Если TTL истёк и другой процесс взял лок, мы удалим чужой.

- При `acquire()` генерировать уникальный owner ID (`crypto.randomUUID()`) и писать его как значение ключа
- `release()` — Lua-скрипт: `if redis.call('get',KEYS[1]) == ARGV[1] then return redis.call('del',KEYS[1]) else return 0 end`
- `waitAndRetry` — polling по `GET` ключа (проверка существования, не значения)

## 2. Backchannel logout — проверка `events` claim
**Файл:** `bff/src/controllers/backchannel.controller.ts`

OIDC Back-Channel Logout требует `events: { "http://schemas.openid.net/event/backchannel-logout": {} }`.

- После `jwtVerify` добавить проверку:
  ```ts
  const events = payload.events as Record<string, unknown> | undefined;
  if (!events?.['http://schemas.openid.net/event/backchannel-logout']) {
    res.status(400).send('Missing backchannel-logout event');
    return;
  }
  ```

## 4. Добавить `express.json()`
**Файл:** `bff/src/main.ts`

Прокси POST/PUT/PATCH передают `req.body`, но `express.json()` не зарегистрирован. NestJS не регистрирует его автоматически.

- Добавить `app.use(express.json())` перед session middleware

## 8. `session.reload()` — express-session поддерживает
express-session Session object поддерживает `.reload(cb)`. Проверка: OK, метод существует. **Исправление не требуется** — это warning от агента был ложным.

Однако стоит убедиться, что typing корректен. Если TypeScript не видит `reload`, нужно добавить Augmentation в `session.d.ts`.

## 9. Redis sAdd + expire — pipeline
**Файл:** `bff/src/services/redis.service.ts`
